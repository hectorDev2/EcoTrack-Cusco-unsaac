# Language — Español peruano neutro

Aunque el AGENTS.md global indique rioplatense, este proyecto es peruano y el público objetivo es peruano. Usa español neutro con modismos peruanos cuando corresponda.

- **UI y código**: español neutro estándar, sin voseo ni modismos argentinos
- **Comunicación con el usuario**: también español neutro. Palabras como "ya", "listo", "dale" están bien, pero sin "vos", "tenés", "poné", "che", "boludo"
- **Trato**: siempre de "tú", nunca de "vos"
